# 🃏 Yu-Gi-Oh! Deck Builder

An **online multi-user website** tailored to help users filter, search, and analyze Yu-Gi-Oh! cards and build their best deck.

## ✨ **Features**

- 🔍 **Advanced Card Search** - Search by name, attribute, archetype, type, level, and race
- 🃏 **Card Database** - Access to the complete Yu-Gi-Oh! Pro Deck API
- ❤️ **Personal Favorites** - Save and manage your favorite cards
- 👥 **Multi-User Support** - Each user has their own isolated experience
- 📱 **Responsive Design** - Works perfectly on desktop and mobile devices
- 🎨 **Modern UI** - Beautiful Bootstrap-based interface with custom styling

## 🚀 **Multi-User Architecture**

- **Session-based user management** - Each visitor gets a unique session
- **Isolated favorites** - Your cards are completely separate from other users
- **Persistent storage** - Favorites survive browser restarts and device changes
- **Scalable design** - Ready for production deployment with multiple concurrent users

## 🛠️ **Technology Stack**

- **Backend**: Node.js + Express
- **Frontend**: EJS templates + Bootstrap 5
- **Sessions**: Express-session for user isolation
- **APIs**: Yu-Gi-Oh! Pro Deck API for card data
- **Styling**: Custom CSS with Matrix-style fonts
